# 🛡️ Enhancing ICS Intrusion Detection using Large Language Models

This repository implements anomaly detection in Industrial Control Systems (ICS) using both traditional deep learning models and transformer-based architectures like BERT, DistilBERT, and SecBERT.

## 📊 Models Supported

### 🧠 Classical Machine Learning:

SVM (Support Vector Machine)

Random Forest (RF)

AdaBoost

k-Nearest Neighbors (k-NN)
### 🧠 Classical models:
- Autoencoder (AE) , CNN, LSTM
-
### 🔐 Transformer-based models:
- BERT
- DistilBERT
- SecBERT (security-tuned)

> These models perform forecasting of the next sensor value using historical time steps.
